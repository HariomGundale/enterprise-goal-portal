# AtomQuest PMS

Enterprise Goal Setting & Performance Management System (PMS) built with Next.js, TypeScript, MongoDB Atlas, Tailwind CSS, and ShadCN UI.

## Features

- JWT Authentication
- Role-Based Access Control (RBAC)
- Goal Sheet Creation & Approval Workflow
- Quarterly Check-ins (Q1–Q4)
- Admin Dashboard & User Management
- Analytics Dashboard
- Shared Goals
- Audit Logs
- Notification Center
- Responsive Enterprise UI

---

## Tech Stack

- Next.js 16
- TypeScript
- MongoDB Atlas
- Mongoose
- Tailwind CSS
- ShadCN UI
- React Query
- Zustand
- Recharts
